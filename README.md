# bash-pamoka-03

Šablonai ir patikros 03 pamokos (Bash skriptai) užduotims 1–3.

```
scripts/patikra.sh      1 užduoties šablonas (užpildykite TODO)
starteris/              2 ir 3 užduočių šablonai
testai/tikrinti.sh      patikra: bash testai/tikrinti.sh 1 (arba 2, 3)
```

Naudojimas:

```bash
cd ~/Desktop/devops
git clone https://github.com/dkoncius/bash-pamoka-03.git pamoka-03
cd pamoka-03
bash testai/tikrinti.sh 1
```
